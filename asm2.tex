\subsection*{1.a}

The accepted string in $L$ should be simplified first. Observe that since $w=(aba)^x$ for any $x \geq 0$, we can rewrite $w^R$ as:

$$w^R \equiv ((aba)^x)^R \equiv ((aba)^R)^x) \equiv (aba)^x \equiv w$$

And $L$ can be modified to:

$$L = \{www | w \in (aba)^*\}$$
$$L = \{w^3 | w \in (aba)^*\}$$

Assume $L$ is regular, then there exists a pumping length $k$ for $L$. Let's choose $s = (aba)^{3k}$, $|s| \geq k$; $s \in L$ since $(aba)^{3k} \equiv ((aba)^{k})^3 \in L$.

Observe all decompositions of $w=xyz$ such that $|xy| \leq k$ and $|y| \geq 1$:

\begin{align*}
&x=(aba)^n, \: n \geq 0\\
&y=(aba)^{3m}, \: m\geq1, \: n+m \leq k\\
&z=(aba)^{3k-3m-n}
\end{align*}

Choose $q$ to obtain a new pumped string $s'=xy^qz$: 

$$s' = xy^qz = (aba)^n(aba)^{3mq}(aba)^{3k-3m-n} = (aba)^{3(k+m(q-1))}$$

Note that $s' \in L, \: \forall q\geq0$. This is because regardless of $q$'s value, $aba$ will always be multiplied by a multiple of 3 in the end, due to the presence of 3 on one side of the multiplication of $aba$'s exponent, meaning $aba$'s exponent will always be a multiple of 3. Therefore the Pumping Lemma does not work here, in fact we can derive the regular expression for $L$ since it is regular. The regular expression can be trivially obtained since the only condition given in $L$ is a Kleene star of the substring $abaabaaba$:

$$L = (abaabaaba)^*$$

\subsection*{1.b}

Assume $L$ is regular, then there exists a pumping length $k$ for $L$. We can choose arbitrary string $s = 0^k 1^k 0^k, \: |s| > k; s \in L$ since the number of $01$ and $10$ in $s$ are both 1.

Observe all decompositions of $s = xyz$ such that $|xy| \leq k$ and $|y| \geq 1$:

\begin{align*}
&x = 0^n, \: n \geq 0\\
&y = 0^m, \: m \geq 1, \: n+m \leq k\\
&z = 0^{k-m-n} 1^k 0^k
\end{align*}

Choose $q$ to obtain a new pumped string $s'=xy^qz$: 

$$s' = 0^n (0^m)^q 0^{k-m-n} 1^k 0^k = 0^{k+m(q-1)} 1^k 0^k$$

If $q' = 0$, then $s = 0^{k-m} 1^k 0^k$. As long as $k - m > 0$, the string still starts with a block of 0, goes to a block of 1, and ends with a block of 0. The count of $01$ is still 1 and the count of $10$ is still 1, so the number of $01$ and $10$ are both 1 and $s' \in L$.

If $q = 2$, then $s' = 0^{k+m} 1^k 0^k$. The count of $01$ and $10$ are still both 1 for the exact same reason, so $s' \in L$.

So the pumping lemma fails. In fact, we can prove that $L$ is regular by giving its regular expression. The regular expression is trivial to produce since we know already that $\epsilon, 0, 1$ are already $\in L$ (vacuously true) and our previous testing gives the condition that $w \in L$ if it begins and ends by the same letter:

$$L = \epsilon \cup 1 \cup 0 \cup 0(1\cup0)^*0 \cup 1(1\cup0)^*1$$

Observe all decompositions of $s = xyz$ such that $|xy| \leq k$ and $|y| \geq 1$:

\begin{align*}
&x = a^n, \: n \geq 0\\
&y = a^m, \: m \geq 1, \: n+m \leq k\\
&z = a^{k-m-n} b^{2k} a^k
\end{align*}

Choose $q$ to obtain a new pumped string $s'=xy^qz$: 

$$s' = xy^qz = a^n (a^m)^q a^{k-m-n} b^{2k} a^k = a^{k+m(q-1)} b^{2k} a^k$$

If $q = 0$, $s' = a^{k-m} b^{2k} a^k$. The number of $a$ in $s'$ is $(k-m) + k = 2k-m$, while the number of $b$ is $2k$. Since $m \geq 1$, $2k-m \neq 2k$, which causes the count of $a$ and $b$ to be different. Furthermore, $(s')^R = a^k b^{2k} a^{k-m} \neq s'$, so $s'$ is no longer a palindrome. Thus, $s' \not \in L$.

\subsection*{1.d}

Assume $L$ is regular, then there exists a pumping length $k$ for $L$. We can choose arbitrary string $s = a^kb^k, \: |s| > k; s \in L$ since we can choose $x = a^k$ and $y=b^k$ and the number of $a$ in $x$ is equal to the number of $b$ in $y$ since they're both length $k$. 

Observe all decompositions of $s = xyz$ such that $|xy| \leq k$ and $|y| \geq 1$:

\begin{align*}
&x = a^n, \: n \geq 0\\
&y = b^m, \: m \geq 1, \: n+m \leq k\\
&z = a^{k-m-n} b^k
\end{align*}

Choose $q$ to obtain a new pumped string $s' = xy^qz$:

$$s' = a^{k+m(q-1)} b^k$$

When $q=0, s' = a^{k-m}b^k$. Since the sequence of $a$'s is guaranteed to be shorter than the sequence of $b$'s, we can actually select substring $x$ to cover the entire sequence of $a$'s and also a certain section of the $b$ sequence, denoting the length of the $b$ sequence covered by $x$ to be $t, t < k$, resulting in $x = a^{k-m+t}$.Then $y$ is forced to be covering the remainder of $s'$ which is $b^{k-t}$. The value $t$ is chosen in a way such that since we've incorporated a certain number of $b$ from $y$ into $x$, originally $\#_a(x) < \#_b(y)$, but after the incorporation the number of $b$ from $y$ is reduced, resulting in a balanced $\#_a(x) = \#_b(y)$.

The same thing happens for any arbitrary number of $q, q \not = 1$ (there would be no pumping if $q=1$), so regardless of any pumping, $s' \in L$. This means that the pumping lemma has failed to prove $L$ to be not regular. 

In fact, we can use the exact same shifting technique to prove that $L$ is regular. If inside an arbitrary string $w$ where $\#_a(x) \not = \#_b(y)$, then for every right-shift performed by $x$ (to incorporate the left-most letter of $y$), or every left-shift performed by $y$, the difference between $\#_a(x)$ and $\#_b(y)$ will shift by 1, eventually reaching a balance of 0.

Therefore, the regular expression for the regular language $L$ is simply:

$$(a+b)^*$$
